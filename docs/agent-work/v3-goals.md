## 目标二：实现作品上传与管理

提供站主可持续维护作品的能力，完成从上传到公开展示的完整流程。

- 受保护的站主管理入口；普通访客浏览已发布作品。
- 上传真实封面、详情图片及选定的视频/其他作品素材；可填写标题、分类、介绍、显示顺序和必要说明。
- 支持保存草稿、预览、发布、编辑、替换素材及撤下作品；管理侧草稿与公开网站分离。
- 上传有进度和明确的成功/失败提示；文件与作品记录持久保存，服务重启后仍可使用。
- 为公开展示生成适合网页的素材版本；保留原文件与必要来源记录，明确文件限制和存储方式。
- 作品文件使用服务器挂载到 `/datastore` 的私有对象存储，Docker只读提供经授权的网页版本；数据库和暂存使用本地持久卷。日常HTTPS上传，SFTP可批量导入为草稿；不直接把存储目录公开为网站。
- 首批真实作品通过这套流程入库，并在总览、分类和详情页实际展示；数量与分类覆盖由用户提供的作品确定。

**完成标准：**站主能独立完成“上传 → 预览 → 发布 → 修改/撤下”，跨会话仍保留数据；未发布作品不可由公开接口或页面读到；上传与恢复验证使用独立测试数据。
