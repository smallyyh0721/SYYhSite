## 页面需求

- 这是为用户review准备的独立模块：漂亮而清晰的“素材预览”和“作品布局”两个视图。
- Day沿用#EDF6FF/#143453/#145EC4，Night#0A0A0E/#F3F1EA/#C8FF2E，日系电影感，留白/柔和层次/圆润控件；不使用装饰细线、方框、虚假终端、代码状态标签。键盘focus应明显。
- 素材视图：人物大图，招呼分镜，四座岛Her/ZZZ/FFF/COS，无岛环境；用自然标题/简短用途帮助判断，明确“概念预览”。支持点击放大、关闭、前后浏览。
- 作品视图：大幅主视觉、全部/Her/ZZZ/FFF/COS主题筛选、精选排序、三列错落图片展示；390/320手机一至两列安全无溢出；同一主角作品的布局概念。
- 用户说“先不放真实作品”：图片可用本次素材作布局示意并明显标注“布局占位”，不能暗示正式作品，不编造标题日期/客户/点赞/个人事实。即使只有一类一个概念，也可通过同图不同安全裁切模拟多个比例，但不要假装有多件作品。缺真实图片用柔和渐变和短文案，不画棋盘格或破图。
- 点击展示大图dialog，Previous/Next在当前可见组中切换，说明区可展开，关闭恢复触发焦点和列表滚动；Esc/ArrowLeft/ArrowRight可用，focus限制在dialog内，手机有大关闭目标。选择Day/Night保存当前本地偏好，尊重减少动态。
- 不做正式视频播放器或模型：分镜不能伪装成视频；形象图不能伪装成3D。所有演示是staticreview，用自然简短文案说明。

## 素材契约

Codex会创建 `manifest.json`，结构如下：
```
{"version":1,"title":"第二版素材预览","assets":[{"id":"character","title":"人物外观","category":"character","path":"images/character.png","description":"成年人物设定预览","status":"preview","theme":"neutral"}, {"id":"island-sky","title":"Her","category":"island","path":"images/island-sky.png","description":"虚拟人物","status":"preview","theme":"concept","workTheme":"Her"}]}
```
id还会有greeting-storyboard、environment-day、environment-night、island-ancient、island-apocalypse、island-home。Assets陆续进入，fetchmanifest并容忍尚未生成的图片；无404红叉。图片失败给诚实短状态，可重新加载。内容由manifest渲染，不写死未提供路径。hero可选character；岛图透明contain，不能切掉下部或把岛背景框死。
