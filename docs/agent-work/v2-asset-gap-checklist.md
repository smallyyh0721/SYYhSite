# 第二版准备：缺失素材、四岛 review 与作品展示规划

更新：2026-10-14，北京时间。依据用户本轮四项要求、当前源码、运行素材与参考站观察整理。本轮完成清点和方案记录；下表是待制作/待补充项，不代表已生成或接入。当前应用仍沿用[运行基线](current-baseline-next-version.md)，阶段台账与线上版本未改。

这里的“第二版”指当前 draft 后的下一次设计版本；素材准备对应既有 P3，网站集成对应 P4，不把版本称呼改成新的阶段编号。

## 1. 本轮已明确的方向

1. 设计 HELLO STRANGER 的正式 3D 人物，并与 About 使用同一角色身份。
2. 四座岛一起 review：二次元岛使用《鬼灭之刃》无限城方向；末日星球使用赛博坦星球末日方向；远古地貌参考亚特兰蒂斯概念；天空岛沿用天空与建筑方向接受复核。
3. 作品展示复刻[RyuSe1 的 Gallery](https://ryuse1-studio.com/#/gallery)的浏览和查看交互，配色沿用当前 Day 蓝白 / Night 暗黑及现有强调色。
4. 全站停止以单线条、直角方框组织视觉。布局改用图片、留白、实色色块、柔和阴影与圆润控件。此要求同时覆盖导航、作品、About、Story、留言、弹层和状态画面。

以上替代旧设计中依赖漫画边框、细线 HUD 和横向作品胶片的建议。既有欢迎→CONNECT→招呼→Hub、四岛菱形运动、手机先选后进、真实 URL 与返回恢复继续作为行为基线。

## 5. RyuSe1 作品展示复刻范围与布局

### 本轮观察到的参考行为

2026-10-14 通过浏览器打开[首页](https://ryuse1-studio.com/)与[Gallery](https://ryuse1-studio.com/#/gallery)：

- 首页有大型轮播主视觉、序号/选择控件、暂停控件及精选作品入口。
- Gallery 实际入口为 `#/gallery`；有 All/分类筛选、Newest/Popular 排序。
- 桌面截图显示三列图片展示，圆润边缘、柔和底色、标题和日期等轻量信息；当前参考首屏大量竖幅图片。
- 点击作品成功打开 dialog：大图、标题、日期、分类、`1 / 60` 计数，以及 Close / Previous / Next 按钮。

观察限制：本轮未完成筛选结果、排序结果、Previous/Next 切换结果、键盘关闭、手机布局、悬停细节和转场时长的可靠复核；这些是后续交互研究/集成的验收项，不能标为已实测。参考站的细线分隔不纳入本站视觉方案，执行用户“取消单线条与方框”的新要求。

### 本站第二版布局建议

| 区域 | 桌面规划 | 手机规划 |
|---|---|---|
| 作品总览 `/works/` | 大幅精选主视觉，随后分类/排序，再进入三列图片画廊；标题、日期、分类保持轻量 | 主视觉单列；分类可换行或横向滑动；图片在可读前提下双列，窄屏/横幅作品使用单列 |
| 四主题作品页 | 同一 Gallery 布局，进入时预选对应岛的主题；显示正式岛名、短介绍、作品数量 | 保留主题选择与返回四岛；筛选控件不压缩到难点按 |
| 图片展示 | 按作品原始比例组织错落排布，避免强制裁成同尺寸方块；图片有轻微层次和留白 | 按阅读顺序排图；保留主体、安全裁切和明确标题 |
| 点击作品 | 打开大图弹层，前后切换当前筛选结果；说明和过程图可在弹层内展开或进入完整详情 | 接近全屏的大图查看，明显关闭与上一件/下一件控件；滑动切换列为待验证增强 |
| 作品详情 `/works/[slug]/` | 保留可分享的真实 URL、完整介绍、角色/媒介/时间和过程图；关闭/返回恢复列表 | 刷新与直接链接仍可读；返回恢复主题、排序、滚动及焦点 |

这是规划，尚未制作新版页面或弹层设计稿。展示顺序、分类和作品数量都由真实内容驱动。参考站同时显示 Popular 控件和点赞数，但实际排序算法尚未核实；本站尚无热度数据，初版建议“最新 / 精选”，若保留“热门”则须先补真实统计来源，不能编造点赞。

## 7. 建议补齐顺序与交付判定

1. **先出能 review 的设计包：** 正式人物候选设定、四岛参考板/同镜头概念、岛名候选、新版作品总览/大图查看/手机布局、全站去框线规范。
2. **然后制作源资产：** 人物建模/绑定与招呼动作；四岛正式日夜及分层；底板/云层；品牌与状态组件。
3. **同步补内容：** 真实作品、简介/兴趣/工具/时间线、故事、联系方式。艺术方向可自主提出；个人事实与项目履历由用户提供。
4. **素材交付后集成：** 作品 Gallery/弹层与独立详情、视频、背景、正式人物、全站视觉；再执行目标浏览器/手机、日夜、减少动态与失败路径验证。
