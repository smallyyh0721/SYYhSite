# SYYH Signal · 设计审核 v1

打开 `index.html` 查看 10 组设计图；文件可离线使用，无安装步骤。`screens/00-overview.png` 是桌面总览；每张图同时有 PNG 和可编辑 SVG。

这是一份静态设计交付，不是生产网站或可点击地图原型。原有 `prototype/` 草稿未改动。只在用户批准设计后搭建。

- `../../docs/design-proposal-v1.md`：设计、页面、交互、响应式与审核项。
- `../../docs/implementation-plan-v1.md`：技术选型、架构、路由、相机、素材预算、留言服务、部署与验收。
- `../../docs/reference-notes.md`：HANDOFF 参考研究、源码证据、已有截图与尚未完成的实测。
- `references/`：本次只读抓取的公开参考源码与访问记录，非用于网站的媒体资产。浏览器失败时不能声称完成实时交互验证。
- `render-design.mjs`：此轮静态 SVG/PNG 的生成源；其 Sharp 路径是本机依赖位置，可按机器调整。

概念人物、浮城、街区及图中文案用于审核。真实个人资料、作品、联系方式和 Story 素材上线前替换。生产字体自托管，当前图片使用本机回退字体。
