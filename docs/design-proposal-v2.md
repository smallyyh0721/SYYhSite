# SYYH Signal · 设计修订 v2

状态：待审核，仍未搭建网站。本次在 v1 之上增加全站 Day/Night 和四个具有独立造型的悬浮岛。v1 的频道、内容页结构与访客入口继续保留；v2 覆盖 v1 仅暗色世界及四岛同款广播站的视觉决定。

需求澄清：用户所说“3D 动画跟随鼠标”指 **01 / VISITOR ACCESS 右侧的人物**。该区域需要真正 3D 人物，具体形象后续设计。人物视线、头部和上身跟随与 Hub 镜头旅行分别实现。详见 [visitor-avatar-plan.md](visitor-avatar-plan.md)。旧耳机人物是占位，不是已确定角色。

## Day / Night

将“day（蓝白命令）”按“蓝白明亮”理解。全站 HUD 放置 Day / Night 两个明确选项，桌面在右上，手机放顶部主题菜单。用户选择保存本地，刷新与切页保留；没有保存选择时先用现有 Night。不会用设备主题或时间覆盖用户的明确选择。

| 层级 | Day：蓝白明亮 | Night：当前暗黑 |
|---|---|---|
| 页面 | 淡蓝白 `#EDF6FF` | 黑 `#0A0A0E` |
| 面板 | 白 `#FFFFFF` | `#15151C` |
| 正文 | 深海蓝 `#143453` | 暖白 `#F3F1EA` |
| 次要正文 | 灰蓝 `#526B84` | 灰 `#A3A2AD` |
| 主操作 | 深蓝 `#145EC4` + 白字 | 荧光绿 `#C8FF2E` + 黑字 |
| 天空 | 淡蓝、柔和白云 | 蓝黑夜空、少量星点 |
| 岛屿光照 | 柔和日光、蓝灰阴影 | 冷月光、窗灯、局部发光材质 |

完整候选 token 在 `design/review-v2/theme-proposal.json`，没有修改已存在的 `design/tokens.json`。实施时将 day 加入 token 生成器，并检查所有旧组件的 `signal` 等硬绑定。低对比 hairline 只作装饰；控件边界独立使用可读 control-border。

主题切换同步 DOM 的颜色/控件及入口 3D 人物灯光；若四岛最终选择 3D 实现，再同步世界背景、雾、环境光和发光强度。人物和岛的形状、路线和镜头位置不因主题变化，切换不重载页面。普通模式约 400ms 平滑切换，减少动态时直接改变。避免只加一层白色滤镜，也不把夜间模型简单漂白。

About 的 Paper 仍可保留为局部阅读模式；它不是第三个全站 Day。Night 中打开 Paper 只影响阅读区，回到 Hub 仍为 Night。

## 四座浮岛的造型

四座岛共享“真实可建模的上部空间 + 完整悬浮底座 + 统一三分之四观察角度”。轮廓、建筑和地貌有明显差异；频道号与 HUD 使用同一设计系统。图中左右分别为同一岛的 Day 与 Night，供审核灯光与材质。

| 设计图 | 主题 | 核心造型 | Day / Night 变化 | 建模重点 |
|---|---|---|---|---|
| 01 | 天空之城 | 纵向塔楼、白石城堡、空中连桥、花园、瀑布与观测站 | 蓝白日景；夜景保留冷轮廓与暖窗灯 | 塔楼分组、桥、悬浮岩根、瀑布简化特效 |
| 02 | 远古地貌 | 宽阔峡谷、层状岩石、风蚀拱门、石柱、碧潭和少量遗迹 | 土色与植被；夜景月光与少量遗迹光 | 岩层轮廓、拱门剪影、植被实例化、水面 |
| 03 | 末日星球 | 破碎行星地壳形成的岛，陨坑、废弃设施、天线、近距离碎片 | 灰锈金属日景；夜景冷边缘与局部橙色裂隙 | 可踏入的上层平台、裂壳、残塔，碎片运动幅度受限 |
| 04 | 二次元宅岛 | 创作住宅、书架、电脑、游戏角、手办陈列、屋顶和樱树 | 清新住宅；夜景暖窗、克制粉青灯 | 房屋外观与少量可见室内；小物合批、贴图表现藏书 |

“天空之城”按原创空中城堡意象处理，不直接复制特定电影。宅岛海报和手办保持原创，不包含未经提供的角色素材。

岛的视觉主题与内容栏目分开配置：Works、About、Story、Board 可以挂在任意一座岛上。此次先确认造型，栏目与岛的对应关系留作下一步设计决定，不由生成图锁定。

## 网页呈现

Hub 从 v1 的同款线稿岛调整为四种独立造型；采用 2.5D 视差图还是完整 3D 模型仍待选定，不因人物需求自动升级为 3D。远景看清四个轮廓，近景看建筑和地貌。HUD、路线、坐标和动作按钮仍保持克制的线条系统；不要让全部岛同时强发光。聚焦岛加一圈细轨道、频道名和明确的进入操作。

默认是上下左右移动鼠标旅行。指针停留在按钮/HUD 时冻结镜头，抵达岛附近后吸附，再点击进入。移动端用拖动；低端设备和减少动态模式提供静态全景/频道列表。四个岛同时驻留在一个世界，旅行不是切换四张互不相干的图片。

生成的概念图用于确定造型、气氛和灯光。它们是二维图片，尚未变成 GLB 模型；实际浏览器视角变化需要后续建模、材质和优化。Day/Night 的两幅图也是灯光目标，不能承诺生成图两侧像素级几何一致；建模阶段使用同一几何确保一致。
