12 格卡片全部标「布局占位」。排序只有「精选」。大图 dialog 用 `History.prototype.pushState` 写入真实 `/works/[slug]/`，避免假 hash，也不引入拦截路由。关闭走 `history.back()`。详情页有四主题入口和缺失过程图空状态；返回链接读 `sessionStorage` 的 `syyh-works` 以兼容 Shell 已有滚动恢复。
