# SYYH Signal · 网站设计方案 v1

状态：待设计审核。此轮交付静态 SVG/PNG 设计图、参考研究及代码实施方案；生产网站尚未开始搭建。现有 `prototype/`、组件包及 tokens 未修改。图中按钮、表单和地图都是绘制的设计状态，不是已实现的交互。

## 定位与体验主线

一个可以“调入”的个人频道：从接通信号、访客入口、夜空浮岛，到作品、本人、故事和留言。桌面优先呈现空间探索，内容页仍采用正常阅读和滚动。气质是成熟的动漫广播片：暗色、克制、精确线条、倾斜粗标题与短中文。避免堆叠无用途的设备指标。

主线：`线条入口 → 游客/昵称 → Hub 移动 → 聚焦浮岛 → 进入频道 → 返回原位置`。

四个频道暂用 Works、About、Story、Board。保留 CH-01…04；最终频道名可以在审核时调整。

## 视觉系统

继续以 `design/tokens.json` 为唯一色彩、间距和字体规范来源。审核图用了本机字体回退以保证离线可阅，生产字体按下表自托管；字符宽度变化须重新校验换行。

| 层级 | 规则 |
|---|---|
| 基底 | `void #0a0a0e`、`surface #15151c`、`ink #f3f1ea`、`ink-muted #a3a2ad` |
| 主信号 | `signal #c8ff2e` 用于入口、主按钮和在线信号 |
| 频道 | Works 黄 `#ffd60a`；About 粉 `#ff3d8b`；Story 青 `#34e1ff`；Board 绿 `#c8ff2e` |
| 占比 | 约 80% 暗底与线稿，15% 文字，最多 5% 强色；单屏最多两种强色 |
| 标题 | Barlow Condensed Heavy Italic，desktop 72–120px，mobile 40–64px；每页只一个 hero |
| 正文 | 中文优先，Zen Kaku Gothic New + 自托管 Noto Sans SC 回退；16px 起、约 1.7 行高 |
| HUD | DotGothic16 + monospace，11–13px 仅元信息；关键动作至少 14px |
| 日文 | 少量频道副标题；不得让日文装饰承担操作含义，主要操作有中文说明 |
| 线条 | 框角、坐标、路径 1px；主岛轮廓 1.5px；面板/按钮按需 2–3px |
| 形状 | 方形与倾斜按钮，圆形仅用于信号、轨道和状态标记 |
| 纹理 | 网点低不透明度；扫描线仅入口与跳转；不让纹理干扰正文 |
| 阴影 | 按现有 token 使用硬偏移；没有大面积模糊阴影 |

这是原创线稿方向的审核图。耳机人物、街区与浮岛均为本次绘制的概念视觉，未复制参考人物或图片；“Neon Alley”等为标明的示例项目。真实头像、作品、职业和经历留待录入。

## 旅行与进入：精确交互约定

桌面细指针：鼠标在地图区域的 x/y 映射到世界相机目标，采用时间归一化阻尼；水平和垂直均可移动。不要把整个页面或 HUD 按钮都当作相机输入区。指针进入 HUD/聚焦操作区时暂停目标更新，防止想点击时岛继续移动。

滚轮和触控板同时支持 deltaX、deltaY；Shift + 普通滚轮沿水平移动。滚动事件只在探索地图中消费；内容页保留原生滚动。离开地图后保留视角，不自动归中。

接近岛时温和吸附，聚焦岛显示频道名、说明、按钮和路径。340px 吸附、210px 聚焦是现有草稿的世界单位初值；需按缩放换算，加入进出阈值避免抖动。**未聚焦岛上的普通点击不移动相机**，仅给出抵达提示；聚焦岛点击/Enter 才进入。

移动端：手指拖动地图改变相机；松开后吸附。按钮有独立 44px 以上触摸区域；手势区可使用 `touch-action:none`，内容页不能禁用滚动。频道列表为轻量与无障碍入口，它可直接选择频道，这是明确的辅助导航，和桌面默认旅行交互分开。

键盘：Tab 可访问四个有名称的岛和导航按钮；方向键移动相机，Enter 进入，Esc 返回 Hub。页面切换聚焦至内容标题；从详情返回把焦点恢复至原作品。提供“暂停视角”和“跳过入口”。不隐藏原生焦点轮廓。

## 动效与降级

| 场景 | 设计目标（尚未实测） | 减少动态模式 |
|---|---|---|
| 首次入口 | 0–0.5s 信号线；0.5–1.0s 框；1.0–2.4s 描边标题；2.4–3.5s 指南 | 跳过入口 |
| 相机 | 初始相当于 60Hz 下 0.075 阻尼，按 dt 调整 | 无惯性/无视差，辅助列表可用 |
| 到达聚焦 | 400–600ms 引线/路径描边 | 静态高亮 |
| 进入频道 | 总计约 650ms：缩放、速度线、斜向揭幕 | 200ms 淡入，不闪屏 |
| 漂浮 | 6px/5s，各岛错相 | 停止漂浮、闪烁及路径流动 |
| Story | 正常滚动驱动三段场景，字幕保持可读 | 静态关键帧 + 完整正文 |

把旧规范的全屏 90ms hazard flash 改成局部边缘扫光；不用频闪。音频默认关闭，用户明确开启后才播放。图中 SOUND OFF 是设计状态，音效素材尚未准备。

## 状态与内容

- 昵称：可空、限 24 字，错误用文字解释；仅 sessionStorage 保存，重新打开会话不承诺保留。
- 作品：图片失败展示替代文字和重试；编号、标题仍可导航。空作品集有清楚空状态。
- Story：尚未准备素材时给关键帧阅读版；不能让加载失败遮住整个网站。
- 留言：空、编辑、提交中、成功待审核、限流、网络失败；失败保留输入。纯文本 1–140 字，不允许上传附件。
- 迷路/404：`NO SIGNAL`，显示“返回 Hub”和内容目录入口。
- 页面状态不只靠颜色区分：频道号、文字、位置和按钮共同说明。

## 审核重点与后续素材

先审核五件事：夜色线稿风格、大标题与中文比例、浮岛旅行方式、四频道内容方向、手机版布局。可按图号反馈“02 岛屿更写实 / 01 想用完整动漫立绘”等；审核通过才执行实施方案。
