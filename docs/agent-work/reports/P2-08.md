## 源码事实：现在的背景在动哪些数

`DynamicBackdrop` 只在 `World.tsx` 里挂载。Gate 的 `.environment` 是同一张 `environment-night.webp` / `environment-day.webp` 的静态 `cover`，上面再叠线性渐变，没有云层动画，也没有星点。欢迎屏和 HELLO STRANGER 屏目前看不到 Hub 这套动态。

Hub 背景由五层叠成，容器 `pointer-events: none`、`z-index: -2`，父级 `.world` 有 `isolation: isolate`。

| 层 | 像素从哪来 | 动画 |
|---|---|---|
| `.scenery` | 一张不透明 WebP。Night 运行时 1600×900、`hasAlpha: false`、139,262 字节；Day 1600×900、`hasAlpha: false`、147,960 字节。源 PNG 为 1672×941 | `horizon`：46s、`ease-in-out`、`infinite alternate`。从 `scale(1.02) translate3d(-1%, -.4%, 0)` 到 `scale(1.10) translate3d(1%, .8%, 0)`。元素 `inset: -6%` |
| `.glow` | 两个径向渐变，没有云图 | `light`：24s、`ease-in-out`、`alternate`。平移约 6% 宽、2% 高，透明度 .45 到 1 |
| `.mist` | 两个径向渐变，`filter: blur(24px)`，宽 140%、高 52%、贴底 | `clouds`：26s、`ease-in-out`、`alternate`。`translate3d(-5%, 3%, 0)` 到 `translate3d(5%, -6%, 0)`，透明度 .25 到 .6 |
| `.stars` | 28 个 `<i>`，各 2×2px，位置由 `(i * 37 + 11) % 100` 与 `(i * 23 + 7) % 70` 决定 | `twinkle`：只改透明度和 `scale(.7)` 到 `scale(1.3)`，不改位置。时长 `4 + i % 5` 秒 |
| `.shade` | 全幅线性渐变，无动画，画在上述四层之后 | 无 |

主题只换底图 URL。Day 另把 `.mist` 的静态透明度写成 .8、星层写成 .1。`.mist` 的关键帧自己在写 `opacity`，动画运行时关键帧透明度盖过 .8。`prefers-reduced-motion: reduce` 使用 `animation: none` 之后，Day 的 .8 才会按静态规则留下。

暂停有三条，彼此不同：

- “暂停动态”或 `document.hidden` 把 `data-paused` 设为真，规则是 `animation-play-state: paused`，停在当前帧。
- `prefers-reduced-motion: reduce` 是 `animation: none !important`，动画取消，变换回到样式表里的静止值。
- 岛图自己的 `float`（9s、`translateY(-8px)`）由 `.world[data-paused="true"] img` 暂停。背景模块的减少动态规则只覆盖背景；ChatGPT复核补充：全局 `app/globals.css` 在reduce时对所有元素及伪元素设置 `animation: none !important` 和 `transition: none !important`，实际也停止了岛的漂浮。不能仅从背景局部规则推断全站状态。

前景岛在背景之上：普通岛 `z-index: 2`，前岛 `z-index: 4`，尺寸 `min(48vw, 54svh)`。左右岛在 16%/84%，后岛更小。底部字幕、频道条和暂停按钮盖住下沿。这些都会挡住背景，但是挡的是已经合成好的一张图，不是单独的云层。

世界 v3 的环境提示词要求一张 16:9 底板：去掉四岛、建筑、文字和 HUD，留下远处行星地平线、底部约三分之一的云海，以及外角的体积云。Day / Night 各一张，云和地平线画在同一张不透明图里。

## 由样式百分比推算，未经浏览器测量

`translate3d` 的百分比相对被变换元素自身。`.scenery` 比视口每边多出 6%，宽度约为视口的 112%。水平位移从 -1% 到 1%，全程约视口宽度的 2.24%。按这个比例：1440px 宽约 32px，1920px 宽约 43px，摊在 46 秒上，平均大约 0.7px/s 和 0.9px/s。`ease-in-out` 在两端速度更低，`alternate` 到头还要原路返回，所以很长一段时间内位移更慢。垂直全程约元素高度的 1.2%。

缩放从 1.02 到 1.10，是整张图一起放大，地平线、星空和云海共用同一个变换。`inset: -6%` 加上 1.10 的缩放，边缘仍被盖住，画面外没有新的云进入。

`.mist` 的水平行程更大：元素宽 140%，从 -5% 到 5%，约等于视口宽度的 14%，26 秒走完。它没有云的边缘，只有两团已经模糊 24px 的径向渐变，再叠加透明度变化。

以上都是按 CSS 定义做的算术，不是开发工具里读到的矩阵，也不是肉眼计时。

## 为什么数值在变，画面仍不像真的云在动

运动属性确实会变：关键帧改的是 `transform`、透明度和星点缩放。缺的是可以跟踪的相对运动。

- 云、地平线、Night 星空是一张不透明位图。整体慢移只产生缓慢的推拉，云不会从地平线前掠过，也没有新云从画外进来。
- 46 秒 `ease-in-out` 往返的平移只有视口宽度的大约 2%，两端几乎停住。
- 名叫云的那一层是模糊渐变，没有云块轮廓。行程虽大，看起来是底部明暗在呼吸。
- 28 颗 2px 星只闪不移动；Day 下整层几乎被压暗。底图里的星星则跟着整图一起挪。
- 遮罩、前岛和底栏盖住云海最清楚的区域。眼睛先看见岛和岛的 8px 浮动。
- 欢迎和招呼根本没有挂这套动画，用的是同一张静态封面。
- 暂停、后台和减少动态会把背景动画停住或拆掉。那是停止，不是“正在播放但看不清”的原因。减少动态不会自动停掉以后若接上的 `<video>`，因为现有规则只取消 CSS `animation`。

## 下一版只先补能分层的素材

建议先做 2.5D：无岛的 Day/Night 底板保持地平线稳定，远云和近云各自透明、速度不同，岛继续是现在的独立点击层。可选的低码率循环短视频只作为整层背景的替补，里面仍然不能画岛。透明通道视频不能当成全浏览器方案。验收要在 3–5 秒内用眼睛看出云相对地平线或相对另一层云的位移，同时中央岛仍是焦点。只比较 `transform` 矩阵不算通过。

触摸沿用背景不接收指针。暂停/页面隐藏冻结当前层或视频帧；减少动态、弱设备或视频失败使用静态 poster，避免按暂停时突然跳图。规格、字节预算和文件清单写在 `docs/agent-work/background-next-version.md`。

## HELLO STRANGER 的后续视频

后续做成一次性伸手迎接，不跟鼠标。参考分镜下半幅的构图：人物面向访客，手从身体附近自然伸向镜头，短停，然后进入 Hub。Day/Night 同一机位和同一动作，只换光照。横竖各一套，并带 poster。人物身份仍等用户定稿，Blender 场景要把网格留成可替换槽位。

播放器以后再接：`muted`、`playsInline`、CONNECT 才 `play()`、`play()` 失败或 `error` 时用 poster、`ended` / SKIP / 最长等待都要进入 Hub、减少动态不播放。本轮不生成、不编码、不接入。

这次读到的 MDN `<video>` 页写明：未静音的自动播放会被现代浏览器拦截；`muted` 和 `playsinline` 是布尔属性，写上即生效；多个 `<source>` 时浏览器用它理解的第一个，全部失败后在 `<video>` 上触发 `error`；播到结尾触发 `ended`；`poster` 在下载期间显示。同一页说明各浏览器支持的格式不同，并指向编解码器指南。那份指南本轮没打开。

Intersection Observer 页写明：可以用它判断目标是否进入视口，从而决定要不要跑动画；它只报告大约百分之多少相交，不报告具体哪些像素；回调在主线程。`prefers-reduced-motion` 页写明：`reduce` 表示用户要求减少非必要动效，大幅缩放和平移属于前庭敏感触发。这两条用来约束以后的播放策略，本轮没有切换系统设置，也没有写对应代码。
