## 任务复述

第二版整体视觉：留白、圆润控件、柔和阴影、实色层次、自然文字。去掉装饰性单线条、直角方框、漫画 HUD 和假终端标签。Day 继续 `#EDF6FF` / `#143453` / `#145EC4`，Night 继续 `#0A0A0E` / `#F3F1EA` / `#C8FF2E`。缺的个人事实和素材保持待补，不编履历、故事或账号。

范围是 Shell、关于、故事、留言、概念图失败态、404 和进度页，加上共用原生 SVG。画廊、入口、世界、Avatar、契约和素材由其他模块持有，本模块不改。标准档，一次一个 CLI。

## 实际完成内容

Shell 导航、主题按钮和页脚改成圆角药丸，最小高度 44px。主题按钮用日/月图标加「日间 / 夜间」，写入既有的 `data-theme` 和 `localStorage` `syyh-theme`。链接仍是 `/hub/` 探索、`/works/` 作品、`/about/` 关于、`/story/` 故事、`/board/` 留言。跳到内容、当前频道、从作品详情回到列表时的滚动和焦点都还在。入口和 Hub 仍用沉浸式顶栏。同一路径的 effect 不再抢走跳过链接的焦点。

关于页保留指针采样、离开回正和纸页模式。纸页只改这一页的奶油底和绿色字，不是新的全站配色。舞台包在 `aria-hidden` 里，图注写明画面上的人是中性代理，正式黑长直角色已通过设计、模型仍在制作。简介、兴趣、工具、经历写的是「还没有提供」。Avatar 的 props 没变，`Avatar.tsx` 没改。画布里仍会画出 Avatar 自己的「3D PROXY / IDENTITY PENDING」，窄屏夜间加载时仍可能出现「连接人物信号…」。

故事保留 `#signal`、`#ascent`、`#arrival`，页面上的位置叫「阅读位置」。三章都是待补空状态，关键帧用空地址立刻进入失败留白，没有用岛图冒充关键帧，也没有新写故事正文。`StoryProgress.tsx` 不在允许范围内，全站样式把它的进度条藏起来，section id 仍给它观察。

留言保留校验、honeypot `website`、`Idempotency-Key`、成功后 pending 不进公开列表、文本渲染和 `/api/messages`。邮箱和社交账号写「还没有提供」。失败、发送中和「已经收到，等待审核」是分开的状态。自检把接口全部 stub，没有向公网发留言。

404 是「这一页不存在」，可回四座岛或看作品。进度页删掉旧的 DRAFT V1，以及「日夜岛尚未选」「分层未开始」。已写入的是四岛日夜、横竖环境、近远云和已接入的画廊；角色和伸手影片仍是制作中；个人内容和分享图、自托管品牌字体仍空着。网站 metadata 只保留 SYYH、个人网站用途，以及不索引。

概念图空地址或加载失败时显示「这张图还没有放进来」，日夜横向错位和 3/4 比例还在。故事帧强制 16/9。键盘 `:focus-visible` 仍是 3px。图标内部描边留着。画廊的类名、比例和斜体标题没有改。入口的 CONNECT 和「直接看作品」也没有改。

最终记录之前，脚本自身失败过，产品检查随后改到通过。这些轮次都在同一实现窗口里修完。

| 轮次 | 现象 | 处理 |
|---|---|---|
| 1 | 先点主题再 Tab，焦点从「日间」继续，跳过链接没拿到 | 跳过链接改在未点击的新加载上测 |
| 2 | 故事关键帧懒加载，视口外不请求，失败文案不出现 | 空 `src` 立刻进入失败留白，不发请求 |
| 3 | 圆角量到了没有圆角的 `section#signal` | 改量包着失败文案的画面 |
| 4 | 开发模式 effect 跑两次，第二次把焦点送进标题，跳过链接又失败 | 路径没变就返回，不再抢焦点 |
| 5 | 主题按钮在水合前被点到，点击丢失，日间等待超时 | 最多再点 3 次；预期的 stub 500 和探测 404 不记成意外失败 |
| 6 | `/works/sky-city/` 上同一次点击也丢了 | 返回列表前的主题切换走同一重试 |
| 7 | 产品项已通过，随后 20 次 `appendChild`：测试脚本在 `documentElement` 还是空时插样式 | 改到 `DOMContentLoaded` 再插入，只藏测试浏览器里的 Next 徽标 |
| 8 | 14 项通过，`pageerror` 为 0 | 记入 `checks.json` |
