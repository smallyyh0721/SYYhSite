## 五、审核节点与边界

1. **范围确认：**首发内容、Story 取舍、媒体与管理需求明确。
2. **设计审核：**整体风格及主要页面的桌面 / 手机、日夜预览通过。
3. **站主流程审核：**用独立测试作品完成上传 → 预览 → 发布 → 修改 / 撤下；确认首批真实内容。
4. **发布审核：**对固定的发布候选、实际验证与备份 / 回滚结果审核，在对应授权范围内上线。
