## 实际完成内容

新增 `ThemeWorks`，签名为 `export default function ThemeWorks({ themeId }: { themeId: WorkThemeId })`。已有路由 `app/works/themes/[theme]/page.tsx` 会把它按冻结的 `themeId` 渲染。组件本身不读 `window`，也不读写主题本地存储。

- 可聚焦 `h1`（`tabIndex={-1}`）使用该主题岛名。
- 只渲染 `works` 里 `themeId` 匹配的条目。当前四个主题各有一条本站设计研究。
- 页面写出岛名、主题名、类别，并用 `ConceptImage` 显示 contracts 里已有的概念图。
- 每条研究链到 `/works/${work.slug}/`。页底有「返回四岛」(`/hub/`) 和「全部作品」(`/works/`)。
- 四个主题导航使用 `workThemes[].href`，当前主题带 `aria-current="page"`。
- 文案标明这是本站设计研究，真实个人作品待录入。没有新增客户项目或人物身份。
- 局部 CSS 只用既有 token。320px 改为单列；Day / Night 跟随 `--ink`、`--muted`、`--primary`、`--surface`、`--void`。

`Works` 保留原有精选图和四条作品列表，并在其后之前增加四个主题入口，样式复用 `ThemeWorks.module.css`。这些入口只指向 `/works/themes/{sky,ancient,apocalypse,home}/`，不把 About、Story、Board 当作岛的目的地。

`/draft/` 按任务书写入这一版事实：欢迎页标题为居中的 CONNECT，第一屏不放人物，真 3D 留到连接后的招呼；悬停约 260 毫秒后聚焦；选中岛沿大约 1.35 秒弧线进入菱形轨道的中央前景；手机先点选再点进入；动态背景可暂停；四岛分别进入主题作品；关于、故事、留言只在顶部菜单。正式人物、真实个人作品、过程图、自述、联系方式、双光照、分层、完整 3D、故事正文、字体、音效、域名、HTTPS 和分享图仍列为缺口。
