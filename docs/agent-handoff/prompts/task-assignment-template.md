## 交付与验证

报告路径：docs/agent-work/reports/<task-id>.md，状态ready_for_review。
检查：只选与改动有关、可复跑的命令和关键流程；文档任务不用构建网站，简单样式修改不写复刻实现的单元测试。
截图/运行证据：场景、主题/宽度、路径；视频/3D需区分首次加载降级与加载后行为。
容差/时限（有动画或浮点时）：基于用户可感知结果，不用脆弱字符串精确匹配代替行为。
必须保留：失败记录、未运行/未验证项、接口建议、实际model/effort/session和完成时SHA。
