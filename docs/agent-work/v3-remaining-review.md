## 存储范围说明

- 不创建/绑定 CAM 角色，不要求用户提供密钥，不自动启用 deploy/cvm-cos-credentials.py 或新的角色挂载 unit；旧草案只留档。
- 不预设替换现有挂载或修改桶权限。先验证现有路径；若存在具体读写失败或公开访问问题，提供实际证据、影响和最小修改建议再供 review。
- 历史核验见到 HTTP + public_bucket=1、匿名桶根 200、测试对象 403。这不等于所有对象可公开下载，也不能证明私有写入和持久化成功。保留原记录，后续解释与用户确认的私有桶配置之间的差异。
- 现有挂载对 COS 的传输方式与浏览器访问网站的 HTTPS 是两段链路，应分别核验。网站 HTTPS 不自动证明对象存储链路已加密。
- 不向公网直接暴露 /datastore，不把 COS 凭据放进 Web/API 容器。访客只通过网站获取已发布的衍生素材。
