## 任务复述

把入口接到正式招呼，再接到四岛 Hub。欢迎页只留居中的 CONNECT，不挂人物、Canvas 或 video。CONNECT 之后由 `GreetingVideo` 按日夜和横竖播放一次居中伸手影片；`ended`、跳过、失败或约 8 秒超时都只进入 Hub 一次。四岛使用正式透明素材和菱形轨道。背景是不动的横/竖底板，近云远云单独慢速漂移。影片和海报当时不在 public，走诚实降级，不用中性代理冒充角色。

## 实际完成内容

欢迎页保留居中标题和慢呼吸 CONNECT。招呼阶段挂 `GreetingVideo`：主题和横竖在 CONNECT 时从 `documentElement.dataset.theme` 与 `matchMedia` 锁定，之后改主题或窗口方向不换片、不重播。播放器 `muted`、`playsInline`、不循环。`ended` 才进入 Hub，GSAP 只淡入 HELLO / STRANGER。跳过按钮在底部，点击目标至少 44px。失败、无法播放和 8 秒超时先短停再进入，且只导航一次。减少动态不播影片，海报短停后进入；海报也不存在时提示「画面还在准备。」

四岛按 `useTheme` 取 `islandArt`。主体 `contain`，没有底框。选中岛点亮，其余灰化，光晕用同一张图。图片失败时仍显示名字并可进入原来的主题 URL。260ms 悬停、1.35s 菱形弧线、静止指针不误选、整图点击、手机先选后进、键盘和返回恢复焦点都还在。

`DynamicBackdrop` 使用横/竖底板和独立近/远云。底板没有位移动画。远云 24s / 4vw，近云 14s / 8vw，近云更快。云层放在天空带里，底部淡出，不再用硬边矩形切过岛。暂停和 `document.hidden` 用 `animation-play-state: paused`，恢复不跳位。减少动态时全站样式会把动画写成 `none`，画面停在静态合成。图片失败就卸掉该层，留下配色，不显示破图或实现说明。
