# 动态背景与 HELLO STRANGER 的下一版素材

2026-10-13，Grok CLI。配套分析是 `docs/agent-work/reports/P2-08.md`。本文件是下一版的素材清单和交付规格。本轮没有生成、下载、编码或接入这些文件。表中的分辨率、时长和字节都是预算，要等真实导出后再改掉。

现有 Hub 背景是一张不透明环境图的 46 秒慢缩放和平移，加上模糊渐变和 28 颗原地闪烁的 2px 星。云和地平线画在同一张图里，所以矩阵在变，云也不会相对地平线移动。下一版用分层静图解决这件事。循环视频是可选项。招呼视频是另一条一次性镜头，不拿来当 Hub 背景。

## 推荐顺序

1. 先交 2.5D 静图：Day/Night 无岛底板、远云、近云、桌面和手机两套构图、每套一张静态 poster。
2. 岛继续用现有透明前景，点击区域保持在岛图上。背景层 `pointer-events: none`，叠在岛下面。
3. 分层结果若 3–5 秒内仍看不出云在动，再启用低码率循环视频。视频里同样不能有岛。
4. HELLO STRANGER 的伸手视频单独制作，本轮不进入页面。

禁止把岛再次画进底板或视频。禁止用一层近景浓雾盖住岛的轮廓或热区。禁止把多兆字节的母版直接放进 `public/`。禁止只拿计算后的 `transform` 当作视觉通过。

## 背景静图

命名建议放在以后的 `assets/source/world-v3/v002/`，运行文件以后再定。本轮不创建这些目录。

| id | 内容 | 构图预算 | 通道 | 单文件预算 |
|---|---|---|---|---|
| `base-day-landscape` | 稳定地平线、蓝白天空、远处薄雾。近云留给云层 | 1920×1080 | 不透明 WebP | ≤ 160KB |
| `base-night-landscape` | 同一地平线角度，近黑蓝空、稀疏远星。近云留给云层 | 1920×1080 | 不透明 WebP | ≤ 160KB |
| `base-day-portrait` | 同一地平线，竖屏安全区。避免只把 16:9 `cover` 裁掉云海 | 1080×1920 | 不透明 WebP | ≤ 160KB |
| `base-night-portrait` | 同上，Night | 1080×1920 | 不透明 WebP | ≤ 160KB |
| `cloud-far-day` / `cloud-far-night` | 小而淡的远云，能看出块面 | 宽 2400、高约 800，左右留可移动余量 | 真 alpha WebP | 各 ≤ 100KB |
| `cloud-near-day` / `cloud-near-night` | 更大的近云，云与云之间留空，能看见底板和岛 | 宽 2800、高约 900 | 真 alpha WebP | 各 ≤ 120KB |
| `poster-day-landscape` 等四张 | 底板加两层云的静止合成，作为减少动态、暂停说明和视频失败画面 | 与对应底板相同 | 不透明 WebP | 各 ≤ 120KB |

四张底板与四张云层共八张，合计预算 ≤ 1.2MB，四张 poster 另计。超出预算先评估可见画质与压缩，再降分辨率；不直接改用视频。

画面约束：

- 底板只保留天空、地平线和极远的大气。会移动的云全部放在透明层。Night 远星若要闪，用极少的 DOM 星，不把大片星野和云绑在同一张会平移的图上。
- 云层边缘在图里画软，页面上不再对整层使用 `filter: blur(24px)`。
- 左右要有多余云，避免平移 8% 后露出空边。做不到无缝横移时，用往返，但 4 秒内仍要能看出云缘离开原位。
- Day 与 Night 各画云的颜色。不要用同一张白雾靠 CSS 染色冒充两套光照。
- 不写文字、HUD、水印、棋盘格。不画四岛、建筑、人物。

漂移速度也是预算，等素材进来再调：远云约 24 秒移动视口宽度的 4%，近云约 14 秒移动 8%，地平线保持不动。近云仍慢于岛的聚焦动画，不能成为画面主角。

## 可选循环视频

只在分层静图没有通过下面的肉眼验收时制作。

| 项 | 预算 |
|---|---|
| 内容 | 8–10 秒无缝循环。地平线锁定，只有云在动。无声，无岛，无文字 |
| 变体 | Day/Night × 横/竖，最多 4 条 |
| 画面 | 1280×720 横屏，720×1280 竖屏 |
| 体积 | 每条 ≤ 800KB，硬顶 1.5MB。四条合计超过 4MB 则放弃视频，只用静图 |
| 容器 | 每条同时给无透明通道的 MP4 与 WebM，用多个 `<source>`。浏览器选用它能播的第一个 |
| poster | 用该条第 0 帧导出的静图，沿用上一节 poster 的构图 |

透明通道不列入交付合同。这次读过的 MDN `<video>` 页只确认格式支持不一致，并建议用多个 `<source>`；编解码器兼容表没有打开，也没有做浏览器矩阵。以后若要试带 alpha 的 WebM，只能作为额外候选，并且在目标浏览器上实际播过才能留在页面里。失败时显示不透明 poster，Hub 仍可点岛。

播放约束，供以后写页面时使用，本轮不写代码：

- `muted` 与 `playsInline` 一起写上。MDN 写明未静音自动播放会被拦截；这两个属性只要出现就生效，不能靠 `muted="false"` 取消。
- 世界区离开视口时暂停。Intersection Observer 适合判断目标是否进入视口；它不提供逐像素重叠，回调在主线程，处理要短。
- `document.hidden` 时暂停，回到前台再按当前模式决定是否继续。
- `prefers-reduced-motion: reduce` 时不调用 `play()`，直接显示 poster。MDN 把大幅缩放和平移列为前庭敏感触发；现有整图 1.02 到 1.10 的缩放属于这一类，减少动态应换静止画面，而不是把同一段平移放慢。
- `error`、`play()` 被拒绝、或设备判定不适合解码时，卸下视频，留下 poster 和可点的岛。

## Hub 验收建议

在分层素材接上之后做，本轮不能勾选。

通过：

- Day 与 Night、桌面与不超过 600px 的竖屏，各看 3–5 秒，能指出近云相对地平线或相对远云的位置变化。
- 第 0 秒和第 4 秒的截图叠在一起，云缘错开，地平线基本重合，中央活动岛仍是第一眼焦点。
- 触摸或粗指针仍是先点选、再点进入；背景点不到。
- “暂停动态”后云停住；标签页隐藏后再看，背景没有在后台继续走。
- 系统减少动态时是 poster 或静止分层，背景视频没有播放。
- 视频地址失败时出现 poster，岛的进入、键盘和顶栏仍可用。

不通过：

- 只有 `transform` 或 `animation-play-state` 变了，叠图看不出云缘移动。
- 整张底板连地平线一起推拉，云层之间没有相对运动。
- 近雾把前岛轮廓或点击热区糊掉。
- 背景文件里又出现了岛。

## HELLO STRANGER 伸手视频

身份未定之前，可以先做代理人体的动作预演，不能把分镜里的银发人物写成已定稿。`brief.md` 仍规定人物是构图代理。

动作预算 2.8–3.6 秒，一次性，不循环，不看鼠标：

1. 面向访客，手在身体附近，约 0.4 秒。
2. 手自然伸向镜头，约 1.2 秒。分镜下半幅的前伸、掌心朝前，是这段的到达姿势，不是起始姿势。
3. 停住约 0.8–1.2 秒。
4. 页面转入 Hub。转入不要做进视频里。

构图和现有招呼一致：人物在右侧，左侧把 HELLO / STRANGER、进度和 SKIP 留给 DOM。Day 与 Night 共用机位、焦距和动作时间，只换光照，并与对应的无岛环境底板方向一致。横屏母版预算 1920×1080，竖屏 1080×1920。脸和伸出的手都留在安全区内。

现在的 `.figure` 使用 `mask-image: linear-gradient(#000 65%, transparent 94%)`，600px 以下是 `inset: 40% -29% -12% 18%`。若以后把视频放进这个盒子，手伸到画面下缘会被遮罩淡掉。交付时把手保持在画面上半的可达范围内，或在接入那一轮改遮罩。本轮不改 CSS。

| 交付 | 预算 |
|---|---|
| Blender | 一个可重复打开的场景：摄像机、灯光、动作、环境锁定；人物网格单独成槽，身份定稿后替换并重渲 |
| 视频 | Day/Night × 横/竖。无声。无透明通道的 MP4 与 WebM 各一份。单文件 ≤ 1.2MB。四组容器合计超过 6MB 就减变体，至少留下当前主题的一条 MP4、一条 WebM 和 poster |
| poster | 每条一条，用伸手到达帧。减少动态和播放失败都用它。单张 ≤ 150KB |
| alpha | 不作为承诺格式。只有在目标浏览器实测能正确合成后，才允许多放一条带 alpha 的候选 |

以后的播放器，本轮不接：

- CONNECT 点击之后才 `play()`。欢迎屏不预拉整段视频；需要的话只取元数据。
- 元素带 `muted` 和 `playsInline`，不放默认控件。
- `ended` 后进入 Hub。SKIP 立即进入。若 `ended` 一直不来，最长等待预算 4.5 秒后进入，避免停在招呼屏。
- `play()` 拒绝或 `error`：留下 poster，文字节奏照旧走完并进入 Hub。
- `prefers-reduced-motion: reduce`：不播放，显示 poster，按现有短过渡进入。CSS 的 `animation: none` 不会替视频调用暂停。
- 标签页在播放中被隐藏：暂停视频；若返回时已超过最长等待，直接进入 Hub。
- 不恢复鼠标跟随。现有招呼快照里 Avatar 已传入 `pointerTracking={false}`；视频方案固定为无跟随的一段成片。
