- About从实时3D人物改为Canvas 2D九帧序列。采用已确认的象牙白开口V领、深蓝外套、长黑发人物，九张418×418 WebP合计235,988字节；安装、生产副本及HTTP实际提供的文件均与审核版hash一致。
- 默认显示正面且不自动播放；支持指针/横向拖动、滑块、普通方向键/Home/End、随滚动和自动往返播放。减少动态时禁止自动驱动，保留手动选帧；后台/离屏停播逻辑已实现。
- 日夜主题、纸页阅读保留当前朝向；人物使用自己的完整浅蓝图面，不羽化或滤镜改色。纸页、留言入口及其他页面背景保留。
- About填入用户已经提供的简介、兴趣和工具原文；不编造经历。旧3D工程、GLB、原图及两个独立预览保留。
- 中心图片可用于无脚本/Canvas不可用后备；部分帧失败保留同一人物静帧，全部失败显示明确空状态。
