## 实际完成内容

`Avatar.tsx` 不再读取 `/media/avatar-proxy.glb`，也不再认代理骨骼名。只从正式路径 `fetch` 后用 `GLTFLoader.parse` 解析普通 glTF。没有接 Draco 或 meshopt；正式文件若依赖这两种压缩，会走加载失败。必要骨骼是 `Head`、`Spine`、`EyeL`、`EyeR`，网格名是 `VisitorBody`。缺其中任何一个就卸下场景并降级。`Blink` 与 `Smile` 缺了仍可显示，属性写成 `blink:missing,smile:missing`，不用压扁眼球代替眨眼。其余骨骼保留，不调用 `skeleton.pose()`，不播放 `gltf.animations`。

视线增量按父级 rest 世界四元数写回局部四元数：`L' = (P_rest^-1 * D * P_rest) * L_rest`，使世界朝向是 `D * W_rest`。只写这四根骨骼的四元数。幅度是头 yaw 18° / pitch 10°，脊柱 4° / 2°，眼 8° / 6°。眼的跟随速率是 12，头和脊柱是 6。`Smile` 固定 0.16。眨眼间隔落在 4–6 秒，闭 0.06 秒、停 0.03 秒、开 0.09 秒。呼吸只加在脊柱 pitch 上，幅度 `sin(time * 1.35) * 0.008`。`document.hidden` 时 `frameloop` 为 `never`，减少动态为 `demand`，其余为 `always`。

半身相机视场角 28°。首轮下界是 `min.y + 0.36 * height`，1.7 m 时为 0.612 m，头顶余量 3.5%，默认机位 `[0, 1.18, 2.4]`。该下界已被 F11-01 改掉，当前取景见文末。resize 用加载时存下的 rest 包围盒重算，姿态变化不带动相机。

`data-avatar-loaded` 在骨骼验收后置位。`data-avatar-ready` 只在 `VisitorBody.onAfterRender` 第一次真正画出、且当前没有失败时置位。日间光是半球 `#f4f8fc` / `#d7e4f3` 0.62，主光 `#f7fbff` 1.45，补光 `#c9daf0` 0.4。夜间是半球 `#1c3352` / `#12161c` 0.2，月光 `#9eb6d4` 0.76，暖光 `#e6b48a` 0.34。主题只改灯光和海报地址，不重新请求 GLB，也不清姿态。DPR 上限 1.5。离开时中止 fetch，并释放 geometry、material、texture。StrictMode 里被取消的第一次加载不把状态钉在失败。
