# P5-06 原画构图与可靠截图返修

用户最新需求仍是使用已通过人物原画的动态图片。功能自检已收到；本轮只修模块内视觉，不扩展 About/发布/新素材，不修改原图。

需求：脸和伸手掌清楚，图画边界柔和，同时保留原图姿态。

观察：当前 `.zoom scale(1.1)` 加 `.ken 1.045` 放大过多；桌面 mask 从74%开始、94%已完全透明，手机70%到90%完全透明，伸手的手指在原图最底部，被裁掉/淡掉。1440截图下半部已看不到完整手掌。当前 wash 180vmax + scale3.15 放大到躯干，画面右侧成为巨大的肤色模糊区域。自检 reach 截图在 fade 中段，仍有双手/双脸重影，不能代表稳定到达姿态。

复现：CONNECT→等待reach foreground opacity>.99再截图；1440×900、390×844、320×568、320×844，用本次lead的 check-image-greeting.mjs也能拍到。对照原始六格分镜第三列（手指本来就贴近格子底部）。

期望：伸手稳态完整可辨，细微羽化只消除白格线/拼贴边缘，不能抹掉手；构图留足顶部导航和底部文字/skip空间。背景取海边/天空色区做柔和延伸，避免巨大肤色近景。脸保持原画比例。可以减少前景尺寸/重定位、降低seam zoom至约1.01–1.02、底部仅最后1–2%渐隐，并减少镜头推进；具体以真实截图为准。若不能兼顾请报告原画限制，不伪称伸手已完整。

修复验收：自检截图务必等对应前景层opacity>.99后拍，Day/Night桌面及手机稳态截图肉眼审核；保留所有行为检查（后台、skip、reduce、故障、一次Hub、无视频/GLB请求）。pnpm typecheck。更新自己的报告和证据，lead另做生产验收。不构建或重启共享服务。原始图及共享文件仍归Codex。

补充原画事实：第三列Day的部分指尖本来就越过512px分格线，Night的指尖也贴原画底边；不要求凭空补画原图缺失的部分。目标是保留原画已有手掌与手指，避免10%放大和20%渐隐进一步丢失。以格子现有可见内容为限，报告如实说明，不为完整指尖重新生成素材。
